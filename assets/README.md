# Иллюстрации Brick Lab 3D

В эту папку загрузите три подготовленных изображения из архива:

- `example-custom.webp` — индивидуальный конструктор
- `example-learning.webp` — игра и обучение
- `example-mechanical.webp` — особая конструкция

Карточки главной страницы автоматически показывают эти файлы; если их пока нет, остаётся прежняя схематичная иллюстрация. Сгенерированные изображения являются концептуальными примерами, а не фотографиями готовой продукции.
