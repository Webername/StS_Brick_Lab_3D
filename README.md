# Brick Lab 3D — сайт стартап-проекта

Одностраничный адаптивный сайт проекта № 107645 «Brick Lab 3D» по программе «Студенческий стартап».

## Состав сайта
- `index.html` — главная страница, информация о продукте, последовательность изготовления, стоимость, раздел заявок, раскрывающийся FAQ.
- `style.css` — адаптивный дизайн.
- `script.js` — мобильное меню, текстовый бриф для копирования, резервный вывод наименований грантовых логотипов.
- `favicon.svg` — иконка проекта.

## Государственная поддержка
На первом экране размещены два логотипа и точная формулировка из п. 3.2б технического задания (приложение № 3 к договору № 2156ГССС27/107645). Логотипы подключаются по внешним ссылкам — рекомендуется заменить на локальные официальные файлы (после их получения). При сбое загрузки отображается наименование организации.

## Приём заявок
Для Brick Lab 3D пока не предоставлена ссылка на отдельную Яндекс Форму, принадлежащую проекту. **Сайт не имитирует отправку заявки:** посетитель может подготовить текст брифа, скопировать его, затем перейти на действующую страницу `https://bricklabs.bitrix24site.ru/#b781`, где по черновому отчёту присутствует форма заявки.

После создания отдельной формы для Brick Lab 3D следует заменить данный сценарий на прямое встраивание формы — как было сделано в проекте «Кузница 3D-Игрушек». Нельзя использовать Яндекс Форму другого стартапа.

## Размещение на GitHub Pages
1. Откройте **Settings → Pages** репозитория.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/(root)`, сохраните.
4. Сайт будет доступен по адресу `https://webername.github.io/StS_Brick_Lab_3D/` после включения публикации.
